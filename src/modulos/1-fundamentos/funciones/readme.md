# Módulo: Funciones en JavaScript

En este módulo profundicé en la creación de bloques de código reutilizables, dinámicos y modulares, comprendiendo los beneficios de las funciones de flecha (*Arrow Functions*) en JavaScript moderno.

## 📌 Conceptos Clave Aprendidos

* **Sintaxis Compacta**: Eliminación de paréntesis en parámetros únicos y aprovechamiento del **retorno implícito** (sin llaves `{}` ni palabra clave `return`) para código de una sola línea.
* **Encapsulamiento y Reutilización**: Modularización de algoritmos complejos para ser ejecutados con múltiples variantes de datos sin repetir código.
* **Operaciones Avanzadas**: Implementación de métodos nativos como `.toFixed(2)` para manejo financiero y métodos de expresiones regulares como `.test()`.

## 🛠️ Ejercicios Resueltos y Desplegados

En el archivo `ejercicios.js` desarrollé 5 soluciones integradas que se renderizan dinámicamente en el portafolio:

1. **Convertidor de Temperatura**: Uso de funciones de flecha puras con retorno implícito matemático (`Celsius a Fahrenheit`).
2. **Generador de Etiquetas de Catálogo**: Evaluación rápida de precios mediante operadores ternarios embebidos.
3. **Validador de Emails**: Validación real de cadenas de texto utilizando expresiones regulares (*Regex*) y el método `.test()`.
4. **Conversor de Divisas Profesional**: Simulación financiera con deducción de comisiones variables y formateo decimal estricto.
5. **Calculadora de IMC**: Diagnóstico de salud automatizado mediante evaluación ordenada de rangos condicionales.
