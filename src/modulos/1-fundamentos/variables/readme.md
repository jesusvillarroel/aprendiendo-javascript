# Módulo: Variables y Tipos de Datos

En este módulo aprendí y practiqué los conceptos fundamentales de almacenamiento de datos en JavaScript moderno (ES6+).

## 📌 Conceptos Clave

* **`let`**: Permite declarar variables limitadas al bloque donde se definen, ideal para valores que van a cambiar.
* **`const`**: Se usa para declarar constantes que no pueden ser reasignadas. Es la opción por defecto en JS moderno.
* **`var`**: Forma antigua de declarar variables. Evito su uso debido al *hoisting* y a que no respeta el alcance de bloque.
* **Tipos de Datos Primitivos**: `String`, `Number`, `Boolean`, `Undefined`, `Null` y `Symbol`.
